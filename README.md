# Phishing Email Detection Project

## Introduction
Phishing is a cyber attack where attackers try to steal sensitive information using fake emails.
This project helps detect phishing emails using Python.

## Objective
- To identify phishing emails
- To help users stay safe from email scams

## Tools Used
- Python
- VS Code
- GitHub

## Project Files
- phishing_detector.py : Main Python program
- sample_emails.txt : Sample phishing email text
- README.md : Project documentation

## How the Project Works
1. User adds email text in sample_emails.txt
2. Python program reads the email
3. Program checks phishing keywords
4. Output shows whether email is phishing or safe

## How to Run the Project
1. Open Terminal
2. Go to project folder
3. Run command:
   python phishing_detector.py

## Output
The program displays the result in the terminal.
